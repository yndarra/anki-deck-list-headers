<b>Rename the columns of the deck list on the main screen, e.g. short "Learn." / "Due".</b>

<ul>
<li>Your own text for the Deck / New / Learn / Due headers. Useful when translations are long, e.g. Russian "Изучаемые" / "К повторению" → "Изуч." / "Повтор".</li>
<li>Settings window (Config button). Empty = Anki's own text. Changes apply immediately.</li>
<li>It only changes the header text and finds Anki's columns by their classes, not by position. Columns added by other add-ons are skipped, so it works with them.</li>
</ul>

Companion add-ons: <a href="https://github.com/yndarra/anki-deck-size-column">Deck Size Column</a> and <a href="https://github.com/yndarra/anki-wrap-deck-names">Wrap Long Deck Names</a>.
